# Kantamanto MVP

## Goal

Build a multi-vendor e-commerce marketplace where customers can
discover and purchase products from independent vendors.

## User Roles

### Customer

- Register and authenticate
- Browse products
- Search products
- View product details
- Add products to cart
- Checkout
- Place orders
- View order history

### Vendor

- Register as a vendor
- Create and manage a store
- Add products
- Update products
- Manage inventory
- View customer orders

### Admin

- Manage users
- Verify vendors
- Moderate products
- Manage marketplace activity

## MVP Exclusions

The following features will be introduced after MVP:

- Real-time vendor/customer chat
- AI chatbot
- Redis caching
- Background job queues
- Advanced analytics
- Recommendation system
- Cloud infrastructure
